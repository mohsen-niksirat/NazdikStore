# NazdikStore — تحقیق محصول/محتوا V7 + فازهای C1–C4

## تحقیق کوتاه
بعد از UI مدرن (V6)، کاربر به **محتوا و مسیر کشف** نیاز دارد:

| نیاز | الگو | چرا برای نزدیک استور |
|---|---|---|
| ویترین عمومی فروشنده | اینستاگرام + Google Business | اعتماد + اشتراک‌گذاری لینک |
| خوراک محلی غنی‌تر | اسنپ‌فود discover | کشف غذا/خدمات بدون نقشه |
| ناوبری موبایل | Snapp bottom nav | دسترسی سریع با شست |
| دسته‌بندی در خانه | Digikala chips | کاهش جستجوی خام |

## فازها

| فاز | نام | خروجی |
|---|---|---|
| **C1** | ویترین فروشنده | `/shop/[id]` عمومی: bio، ساعات، محصولات، نظر، دکمه پیام/نوبت |
| **C2** | خوراک محلی | فیلتر دسته + کارت غنی + لینک ویترین |
| **C3** | ناوبری موبایل | Bottom nav ثابت (خانه/نقشه/سفارش/پروفایل) |
| **C4** | بهبود جستجو UI | فیلتر «باز الان» + چیپ دسته در `/search` |

هر فاز → تست smoke → push.
