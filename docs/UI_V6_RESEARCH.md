# NazdikStore — تحقیق UI/UX + فازبندی بصری V6

## وضعیت
رابط فعلی کار می‌کند ولی **خشک** است: کارت‌های ساده، دکمه‌های یک‌شکل، فضای زیاد بدون ریتم.

## تحقیق (الگوهای اپ‌های مدرن محلی/غذا/خدمات)

| منبع | چه چیزی قابل قرض گرفتن |
|---|---|
| **Snapp / Tapsi** | هدر شفاف، چیپ موقعیت، کارت‌های افقی، رنگ برند قوی |
| **اسنپ‌فود** | عکس بزرگ محصول، قیمت درشت، badge تخفیف |
| **Instagram / Pinterest** | فضای تنفس، تصویر اول، تایپوگرافی نرم |
| **Apple Maps / Citymapper** | نقشه تیره، مسیر برجسته، اطلاعات شناور |
| **Iranian fintech** | رنگ آرام + یک accent زنده، آیکون داخل دکمه |

## جهت طراحی (Design thesis)
**«بازارچه محلی زنده»** — کرم گرم + سبز عمیق + طلایی محدود  
نه SaaS خاکستری، نه شلوغی اینستاگرام.

### توکن‌ها
| توکن | مقدار | نقش |
|---|---|---|
| paper | `#F6F1E8` | پس‌زمینه گرم‌تر |
| ink | `#14201C` | متن |
| accent | `#0D7A66` | CTA / تمرکز |
| gold | `#C9972B` | badge / خانگی / جایزه |
| danger | `#B42318` | خطا |
| line | `#E6DFD2` | خطوط |
| radius | `18px / 14px` | نرم‌تر |
| shadow | `0 12px 40px rgba(20,32,28,.08)` | عمق |

### تایپوگرافی
- عنوان: وزن ۸۰۰، tracking کمی باز  
- بدنه: ۱۵–۱۶، leading ۱٫۷۵  
- اعداد فارسی در قیمت/ETA درشت‌تر  

### حرکت
- hover کارت: translateY(-2px) + shadow  
- `prefers-reduced-motion` محترم  

## فازبندی اجرای UI (V6)

| فاز | نام | خروجی |
|---|---|---|
| **U1** | سیستم طراحی | globals.css مدرن + layout/هدر/لوگو |
| **U2** | خانه و تور | Hero جذاب، بنرها، مسیرها |
| **U3** | نقشه و سفارش | کارت‌های غنی، ETA، لیست بهتر |
| **U4** | فرم‌ها | auth/profile/cart/polish |
