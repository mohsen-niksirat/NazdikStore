# NazdikStore V8 — درگیری و کشف (D1–D3)

## تحقیق کوتاه
| نیاز | الگو | ارزش |
|---|---|---|
| تعامل با پست | Instagram like/save | بازگشت کاربر به خوراک |
| جستجو → نقشه | Google Maps «near me» | کشف فضایی از متن |
| گالری ویترین | Google Business photos | اعتماد بصری |

## فازها
| فاز | نام | خروجی |
|---|---|---|
| **D1** | لایک/ذخیره خوراک | API + دکمه روی کارت پست |
| **D2** | جستجو به نقشه | دکمه «روی نقشه» + لینک `/map?lat&lng&radius&q` |
| **D3** | گالری ویترین | نوار تصاویر نمونه + محصول با placeholder رنگی |
